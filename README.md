# SnipasteOCR 截图贴图自动翻译工具

[![开源协议](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

基于飞桨 PaddleOCR / FastDeploy 与智能贴图技术的屏幕文字识别与自动翻译工具。
支持**全局快捷键框选、原地定屏贴图、自动覆盖翻译**，彻底告别繁琐的文件保存与本地磁盘垃圾！

---

## ✨ 核心特性

- 🚀 **原地定屏贴图与自动翻译（核心亮点）**：
  - 按下全局快捷键（默认 **`F4`**），框选屏幕上任意区域或 Snipaste 贴图，松开后**直接在原位生成置顶贴图**，并**自动识别文字并覆盖渲染翻译**！
  - **零文件读写**：全内存图像处理，不向本地磁盘写入任何图片或文本文件。
- 📋 **剪贴板贴图翻译**：
  - 复制图片后按下 **`Alt+W`**，即可直接在鼠标处生成贴图并自动翻译。
- 🌐 **开箱即用免费翻译**：
  - 内置免配置免费翻译引擎（Google / MyMemory），无需申请或配置任何 API 密钥即可立即翻译！
  - 同时支持配置腾讯云机器翻译 API 密钥。
- 🖼️ **强大的贴图交互体验（契合 Snipaste 习惯）**：
  - **鼠标拖拽**：在贴图任意位置按住左键拖动。
  - **滚轮调节透明度**：滑动鼠标滚轮快速调节贴图透明度（20% ~ 100%）。
  - **空格键切换**：一键切换显示“译文”或“原文”。
  - **双击或 ESC**：快速销毁/关闭贴图。
  - **右键菜单**：支持一键复制译文、复制原文、重置透明度。
- 📁 **向下兼容文件夹监控模式**：
  - 如习惯 Snipaste 的 `Ctrl+Shift+S` 快捷保存模式，可在设置中开启文件夹监控功能。

## 💻 快捷键指南

| 快捷键 | 功能说明 | 交互操作 |
| :--- | :--- | :--- |
| **`F4`** | **截屏贴图翻译**（全屏框选） | 框选完毕后原地置顶贴图并自动翻译 |
| **`Alt+W`** | **剪贴板贴图翻译** | 将剪贴板中的图片贴在屏幕上并自动翻译 |
| **空格键** | 切换原文 / 译文 | 贴图窗口激活时有效 |
| **鼠标滚轮** | 调节贴图透明度 | 在贴图窗口上滚动滚轮 |
| **双击 / Esc** | 关闭贴图 | 快速关闭当前置顶贴图 |

> 快捷键可在软件「设置 -> 首选项与快捷键设置」中自由修改（例如修改为 `Alt+Q` 等）。

## 🚀 快速启动

### 运行方式

**方式一：使用 UV（推荐）**
```bash
# 同步环境并安装依赖
uv sync

# 运行程序
uv run python main.py
```

**方式二：使用 Windows 批处理**
- 双击运行根目录下的 `启动SnipasteOCR.bat` 或 `调试启动SnipasteOCR.bat`。

---

## ⚙️ 翻译与热键设置

点击主界面的「**首选项与热键**」或菜单栏「**设置 -> 首选项与翻译设置**」：
1. **翻译服务**：
   - `免费翻译 (开箱即用)`：无需任何配置，支持中、英、日、韩等多语言自动互译。
   - `腾讯云机器翻译`：填写腾讯云 SecretId 与 SecretKey。
2. **快捷键自定义**：自由修改截屏贴图快捷键与剪贴板贴图快捷键。
3. **文件夹监控**：可选开启/关闭对指定保存文件夹的自动扫描。
